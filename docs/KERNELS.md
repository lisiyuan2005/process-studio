# 仿真内核：Slab (DeviceFlow)

只有一个内核。工程的几何是**精确的多边形板层（slab）堆叠**，由并入的 DeviceFlow 0.2.0 内核计算，不是网格上的场。

原来还有一个自带的 level set 内核（均匀网格上的符号距离场）。它在 `0.9.8` 之后从 main 删掉了，代码留在 `archive/levelset` 分支上。用它建的工程打开时会被明确拒绝，并说明该去哪个版本打开，不会被悄悄换到这个内核上跑——两者的几何表示不同，快照互不可读。

## 这个内核能做什么

| | Slab (DeviceFlow) |
| --- | --- |
| 几何表示 | 精确多边形板层堆叠；没有网格 |
| 精度参数 | 保形沉积沿高度的行走步长（z）和平面内圆弧的弦高（XY）；垂直刻蚀、平面沉积和 CMP 与这两个数无关，任何分辨率下逐位相同 |
| 沉积 | 保形、平面；厚度可以直接给，也可以给周期数×每周期速率（ALD）或时间×速率；可带掩膜：先整片生长，再按掩膜柱体逐层裁掉开口之外的部分并入目标材料，等价于理想 lift-off，开口内的侧壁也有膜 |
| 刻蚀 | 垂直（`directional_fraction` = 1）或各向同性（0），不支持中间值 |
| 氧化 | 露出表面向内一层原地变成氧化物，按各材料的 rate 比例消耗，不模拟体积膨胀 |
| 翻片 | 整片翻过来：原来的背面朝上，接下来的步骤做在背面。体积逐位不变，横向按翻转轴镜像（绕 y 翻则 x 镜像） |
| CMP | 平面截断，对所有材料一视同仁 |
| 掩膜 | 无掩膜、Quick Sketch、GDS |
| 3D 视图 | 直接输出几何三角面，按面着色：平面就是两个三角形，用顶点法线插值会在对角线上显出暗纹 |
| 快照 | `.dfz`，DeviceFlow 的 ZIP 状态存档 |

## 三档膜模型（fidelity）

顶栏精度按钮旁边的按钮切换，默认 **simplified**：

- **voxel**（体素）：还是一层层的板，高度精确（5 nm 的膜就是 5 nm），但每层板内部的 x、y 换成格子，每个格子只放一种材料或空。格子分两级：体块格子边长是工程窗口的 1/512（窗口 1.6 µm 就是 3.1 nm）；只有边界上（格子里不止一种材料）才细分成 B×B 个细格，细格不大于工程的 XY 分辨率，B 取 2 的幂、最多 64（1.6 µm 窗口、0.1 nm 分辨率时 B = 32，细格 0.098 nm）。体块不付细分辨率的代价：3D AND 示例 0.1 nm 下全流程结束时只有约 7 万个细分格子。
  - 所有工艺都在细格上算：沉积按细格中心到固体细格中心的距离、竖直刻蚀按细格列、CMP 和翻转照搬细格，和把整个窗口都按细格画出来的结果逐格相同（测试里对拍）。
  - 相同的细分格子只存一份：薄板里重复出现的竖直墙面格子只是引用，不占新的内存。0.1 nm 下 3D AND 示例全流程结束时细分格子本身约 8 MB。
  - 画面按细格画，但整个窗口最多约 2048 格宽：细格更细时显示用的是按 2 的幂合并过的格子，每个显示格取其中占多数的材料。3D 网格是体块面和细格面一起拼成的，拼接处没有 T 形接缝。
  - 两种材料不可能占同一个地方，所以没有接缝、碎片、几何修复这一类问题。
  - 各向同性刻蚀一步算完：「离空腔 d 以内」是格子上的一次距离判断，不分子步，快慢和刻蚀深度、附近最薄的阻挡层都无关。3D AND 示例（1.6 µm 窗口）整个 19 步流程：工程 25 nm 分辨率时 5 s；边界 1 nm 时 19 s；边界 0.1 nm（xyz 都 0.1 nm）时 86 s、峰值内存约 2.2 GB。简化版单是 0.5 µm 的侧向刻蚀就要 127 s。
  - 代价是横向精度：边落在格子上，误差半个格子，圆孔是格子画出来的。侧壁上比一个格子还薄的膜保留一个格子厚，不会消失。
  - 湿法刻蚀和氧化按**腐蚀液的到达时间**算：腐蚀液是液体，开放空间一接通就瞬间充满；在材料里以该材料的速率向各个方向推进，rate 为 0 的材料挡住。格子中心在刻蚀时间内被腐蚀液到达就被刻掉。起点是掩膜开口内与外界相通的开放空间；掩膜外与外界相通的开放空间（原有的孔、沟槽）视为被光刻胶填满，腐蚀液进不去；密封的空腔一旦被刻开就立刻灌满，从那一刻起刻它的壁。多种材料同时刻、各按各的速率，所以快材料下面的慢材料要等快材料刻完才开始；前沿绕过阻挡层而不是穿过去。z 方向：刻蚀推进时，前沿可能在 z 方向弯的板层边界附近（可刻材料上下挨着腐蚀液能进的开放空间、挨着另一种速率的材料、或者一部分挨着可刻材料一部分挨着墙），把板按体块格子的厚度（或工程 z 步长，取大者）切开来算；整层从竖直侧壁刻进去的地方前沿本身是竖直的，不切。算完再按工程的 z 分辨率放前沿：水平的前沿（比如顶面整体往下刻）按面元和刻蚀时间算出精确高度，直接在那个高度切板，不受任何网格限制；真正弯的地方（圆角、半球形空腔）把那一层切成不厚于 z 分辨率的薄板，每块薄板在自己的高度上逐个细格放；竖直前沿穿过的板保持整块。所以 0.1 nm 分辨率时 z 方向也是 0.1 nm，但只有弯曲前沿所在的高度才有薄板，体块的板还是整块。
  - 每个被刻到的格子记住腐蚀液是从哪个表面面元进来的，到达时间就是到那个面元的直线距离（沿视线检查，被挡住就在拐角处转向），所以同一种材料里在视线范围内的前沿是精确的，不是格子步数的累加。
  - 两级格子上：体块格子各是一个节点，细分格子里同一种可刻材料连成一片的是一个节点，所以穿过细分格子的薄阻挡层照样挡住、全在细分格子里的薄膜照样能一路刻过去。入口面元在细格上找、拼成最大的矩形。前沿最后落在细格上：前沿边缘穿过的体块格子逐个细格行精确切，细分格子里的节点逐个细格算。体块格子相隔一个格子，圆孔壁上相邻格子各自最近的台阶面元不同，所以离开节点时沿着相连的入口面元走到离该点最近的那个（隔一个面元看，台阶拐角两边一样远时也能继续走）。圆孔、薄墙、阻挡层几个例子和全细格结果逐格相同。
  - 两级格子上还是近似的地方：细分格子内部的密封空腔当墙；两种可刻材料在细分格子里的交界放在两个节点中心之间（交界处前沿的折线，全细格和两级格子都只准到一两个细格）。
- **simplified**：膜的拐角是直角，每个平面一段，不按分辨率采样，快得多。
- **detailed**：膜的拐角是圆角，沿高度按分辨率采样。

各档的结果分开保存，切回去不用重算。命令行是 `process-studio fidelity [detailed|simplified|voxel]`。

## 高度约定

界面上的高度：晶圆表面在 z = 0，衬底向下延伸到工程窗口的 `zMin`，沉积向上生长。

DeviceFlow 自己的坐标是从 z = 0 的地板向上生长的，所以内核把衬底建成 `|zMin|` 厚的一层，并在所有对外的高度上加回 `zMin`。改工程窗口的 z 范围就改了衬底厚度和上方的余量。CMP 的 `target_z`、截面的纵轴、3D 的包围盒都按工程高度给出，不需要用户换算。

## 不能做的事会明确报错

内核不会把做不到的工艺近似成别的东西。以下情况直接失败并说明原因：

- `directional_fraction` 不是 0 或 1；
- 沉积模式是 `directional`、`evaporation` 或 `fill`；
- 刻蚀既没有目标深度也没有时间。

CMP 步骤如果带了材料列表或停止层，会在日志里说明该内核的 CMP 不区分材料，然后按平面截断执行。

## 代码位置

```
src/deviceflow/                     并入的 DeviceFlow 0.2.0 源码，未做修改（见 src/deviceflow/VENDOR.md）
src/process_studio/kernels/base.py  内核接口：初始状态、单步执行、读写状态、三种视图
src/process_studio/kernels/slab.py  DeviceFlow 适配：步骤翻译、掩膜、状态存档、视图光栅化
src/process_studio/grid.py          工程窗口（`UniformGrid3D`，只当作窗口用）与 `window_grid()`
```

`runner.py`、`protocol.py` 只通过这个接口工作，不判断内核 id。注册表（`kernels/__init__.py`）留着是因为工程要记住自己用的是哪个内核（好拒绝别的），以及某份构建漏装依赖时要能报告而不是崩掉。

## 依赖


内核需要 `shapely` 和 `trimesh`，两者已在 `pyproject.toml` 的依赖里，打包脚本也会一起收进 worker。缺少它们时注册表里就没有可用内核，`describe` 的 `kernels` 是空的并说明原因，不会假装可用。

**各向同性刻蚀为什么慢，以及慢在哪**：profile 真实工程第 31 步（10 nm 的 SiCON 湿法刻蚀，253 个 slab），589 s 里几乎没有一处是"算得多"，全是"同一件事算了很多遍"：每一步问 3,295 次膨胀而只有几十个是不同的（127 s）、每个集合的并集重算（95 s）、`_assemble` 每条边建一个 LineString（560 万次）、板层归一里每对相邻 slab 都做一次边界叠加（50 s）、`clean` 把 GEOS 刚吐出来的合法多边形再修一次再并一次再裁一次（12,000 次）。这些全部去掉之后同一步 **589 s → 279 s**，七种材料体积逐位不变，401 个高度切片上几何差的总面积 6.4e-8 µm²（窗口是 0.09 µm²，也就是网格量级，正是 harmonize 声明的"几何最多移动一个网格步"）。

**还试过两条路，都量了，都退回来了**——记在这里免得下次再试：

- **把简化版前沿的 XY 角也做成直角**（mitre join）：诱人之处是直角膨胀完全不加顶点，前沿就不会一步步复杂下去，实测 state 从 21 个 slab/11,896 个顶点降到 12 个/4,251 个。但**目标材料多刻掉了 37%**：直角拐角比真实前沿多伸出 0.41 r，每步都多伸一次。这不是简化，是算错。
- **把前沿按容差简化掉多余顶点**：从每步深度的 2% 扫到 20%，**顶点反而变多**（11,896 → 15,230），slab 也变多。原因很具体：相邻采样共用同一个 reach 靠的是"环对环完全一致"，简化过的 reach 和邻居不再一致，于是每个采样都独立成为一个 slab。

所以前沿的顶点会一步步累积（真实一步从 205 个涨到 2,994 个）这件事**目前是方法本身的性质**，不是可以顺手抹掉的。真正的下游账单也在这里：第 27 步一个湿法刻蚀把 state 从 35 个 slab/44,685 个顶点变成 249 个/932,203 个，后面每一步沉积、刻蚀和建网格都在为这个买单。
