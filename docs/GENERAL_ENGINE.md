# 通用几何引擎：正确性优先的细化执行

本次先回退 a297261、7490a0a、2b10ee1 的界面/渲染修补，再实现通用计算机制。旧的独立单元块缺少邻域信息，不能作为可信的 AMR 求解结果。历史数据保留，仅用于比较。

## 已改动

1. **输入边界统一**：圆、矩形、任意简单多边形、圆端折线、布尔组合、阵列、GDS 都输出连续 level-set。多边形使用闭合线段距离及奇偶规则；GDS 使用库单位和展开后的实例变换。没有先二值化再重建边界。
2. **距离重建**：保形沉积采用 scikit-fmm 的二阶 Fast Marching 距离重建，替换对离散零交叉点的最近距离。它是 Eikonal 方程的离散近似，并不意味着任意曲面数学上精确。[实现文档](https://scikit-fmm.readthedocs.io/en/master/)
3. **材料不变量**：沉积的内边界取原始联合材料界面的反号；原有材料数组不被重初始化或重新裁剪。加入新膜不得使衬底或已埋藏材料自行移动。图形沉积的显式覆盖语义保持不变。
4. **刻蚀边界**：掩膜定义可达空腔，不再把边缘像素变成不同的垂直刻蚀速率。纯垂直、空间常速情形直接平移掩膜柱体；混合情形仍用一阶 HJ 演化，顶面保护作用于掩膜边界。
5. **计算规划**：网格统一锚定项目原点。由实际掩膜和整条流程的数值 stencil 传播半径生成区域，重叠求解区域递归合并，仅显示具有足够保护范围的 core。没有与器件类型、圆心或单元间距相关的修补参数。
6. **安全退回**：保形沉积的全局距离计算、CMP、自动最高表面和暂未界定局部支持的算子，使用全域细网格重新执行。资源检查在三维初始状态分配之前完成；超预算不产生替代精度结果。

## API

```python
def initializer(grid):
    state = MaterialState(grid)
    state.add_material("Si", grid.substrate())
    return state

adaptive, plan = engine.run_refined_branch(
    initializer, project, branch,
    factor=4, max_nodes=20_000_000,
)
```

initializer 必须在任意请求网格上生成**同一物理初始结构**。不能把粗网格最终快照插值后冒充细网格初始条件。规划信息包含模式、原因、求解区域及真实节点数。细化运行不覆写原工程粗网格快照；结果可单独保存。

factor 当前支持 2 的整数次幂；h = 项目网格间距 / factor。节点预算不是操作系统内存保证：每种材料一个双精度三维场，计算时还需多个临时场，须按机器内存配置预算。全域 1 nm 计算与“1 nm 截面采样”完全不同。

## 必须保留的边界

- 这不是完成版动态 AMR：尚无每步重分块、粗细层通量/ghost 同步或稀疏窄带存储。规划器通过有界局部重算或全域退回避免错误拼接。
- 局部正确性要求 initializer 可在任意子域直接求值；旧快照无法自动满足这一条件。
- 真实项目外边界仍是有限计算域；混合 HJ 使用零法向梯度的数值边界。界面接近外边界时仍需扩大项目范围并验证域尺寸收敛。
- HJ 是一阶；FMM 和零等值面都是离散近似。任意偏移/旋转结构可能仍有随网格收敛的误差，不应靠镜像、平滑、补洞隐藏。
- 保形沉积是等厚几何膨胀，新增每步开始时的外部空气连通性检查：已经封闭的孔洞不会被后续沉积填入材料。尚未实现同一步内 pinch-off 时刻的输运截止；连通性本身也受网格解析度影响。选择性刻蚀是速率缩放几何模型，不包括跨材料遮挡、反应或真实停止层输运。
- API 可以接受复杂版图，不代表已具备全部半导体物理；晶向湿蚀、侧壁钝化、CMP dishing 等仍未实现。

## 验证标准

测试不使用 1T1C 的尺寸作为引擎常量。覆盖偏移圆、矩形、不规则多边形、折线路径，以及纯方向性/混合/各向同性刻蚀的局部与全域结果对比；还覆盖区域递归合并、GDS 旋转和非默认单位、球面/斜面/多物体沉积界面不变性、网格收敛与超预算拒绝。

这些验证针对离散几何和软件一致性，不是实测工艺精度认证。
